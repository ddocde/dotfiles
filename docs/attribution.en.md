# Attribution

The project architecture was developed after a static audit of CNCSMonster/dotfiles. The WezTerm configuration and selected shell interaction preferences was adapted from the user's local configuration based on that repository; its MIT license is retained in `licenses/CNCSMonster-dotfiles-MIT.txt`. Git history was not copied. xdotter 0.5.2 is redistributed under its upstream MIT license; see `vendor/xdotter`.

Reliability and workflow decisions were also compared against chezmoi, Dotbot, and yadm. Only general architectural ideas were adopted; no implementation code or configuration payload was copied. See `docs/open-source-review.md`.
