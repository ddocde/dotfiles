# Decision log

- Shell is the orchestration language; no Rust CLI is required.
- Profiles compose modules; dependencies are a stable DAG.
- Installation and xdotter deployment are separate stages.
- China networking is the default, centralized policy.
- Codex and Claude are the documented npm `latest` exceptions.
- Neovim, Qwen Code, Zellij, Atuin, direnv, KDE, and large shell frameworks are out of scope.
- Claude's npm distribution deprecation is accepted technical debt.
